# Деплой проекта Hoteltroy на сервер

## 1. Подготовка изменений и пуш в GitHub

> Если нет токена для GitHub, создаем Personal Access Token (PAT) примерно на неделю.

```bash
# Добавляем все изменения в git
git add .

# Фиксируем изменения с осмысленным сообщением
git commit -m "Сообщение: что изменили"

# Отправляем изменения на GitHub
Формат команды с токеном рабочий, но лучше использовать SSH-ключи вместо токена в URL, чтобы не светить токен в истории команд.
git push https://troyhotel:<YOUR_GITHUB_TOKEN>@github.com/troyhotel/troyhotel.git main

2. Подключение к серверу
# Подключаемся по SSH
ssh root@217.26.31.151
Пароль лежит на почте (сервер Effusive).

3. Обновление кода на сервере
# Переходим в папку проекта
cd /var/www/hoteltroy

# Пропускаем, Проверяем текущий статус git
git status

# Сбрасываем все локальные изменения
git reset --hard

# Удаляем незадекларированные файлы
git clean -fd

# Обновляем репозиторий
git pull origin main

# Пропускаем, Если нужно клонировать заново, обычно не требуется
git clone https://troyhotel:<YOUR_GITHUB_TOKEN>@github.com/troyhotel/troyhotel.git .


🔹 git reset --hard и git clean -fd полностью очищают рабочую директорию, поэтому используй с осторожностью.
🔹 Последний git clone нужен только если хотите заново клонировать проект в текущую папку.


4. Установка зависимостей и сборка проекта
# Устанавливаем все npm зависимости
npm install

# Сборка проекта (Nuxt 3)
npm run build

5. Перезапуск PM2

5. Полный сброс PM2
⚠️ Удаляет все процессы и конфиги PM2, что может повлиять на другие проекты на сервере.

pm2 kill

rm -rf ~/.pm2

# Запускаем проект заново
pm2 start .output/server/index.mjs --name hoteltroy

# Сохраняем конфигурацию PM2, чтобы автоматически запускался при перезагрузке
pm2 startup

pm2 save

# Просмотр логов приложения, проверка что проект слушает порт
pm2 logs hoteltroy

```
